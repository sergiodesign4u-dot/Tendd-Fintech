# wireframes/ - what breaks forever if you get it wrong

1. **Never color anything here.** Grey is the contract, not a stage of progress. Color goes
   onto copies in `design/`, and a colored page may differ from its grey original by styling
   only. Coloring a file here destroys the structure source for every later stage.
2. **Structure and text belong to this folder.** States, blocks, order and copy are decided
   here (from the IA and the voice), not in `design/`.
3. **`_wf.css` is the single grey stylesheet.** No page level look, no brand, no icons.
4. **`index.html` is the product home page** (the Welcome landing, node 0.0). The hub with
   every screen and state is `overview.html`. Never swap the two.
5. **One page per state.** A screen is not done until every state from the IA spec has its
   own page and a real way out.
