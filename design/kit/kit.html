Component kit

Every component of the product in one place, in Petrol and Paper. A screen is assembled from these classes, inside an .app or .landing host, and carries no style of its own: if a detail is missing it goes into the kit first and onto the screen second. A rule written on a screen looks flawless in the browser and becomes drift at the next stage, where the system derives its tokens from exactly these files.

The level is not a label. Stage 08 splits the CSS in this order and imports it in this order, so a container that sorts above its own parts lands higher in the cascade than the things it contains, and every contextual fix after that reaches for !important.

Organisms

Hosts molecules, or is a screen shell. This is the ceiling; there is no level above it. The shell reflows on container queries, not media queries, so a screen behaves by the width it is given rather than by the width of the browser.

What was authored, and what this kit retired

Extraction can only return what greyscale could express. Everything else is named here so the exception stays deliberate.

authored The filled button, the inverse button, the invalid field. The first exists in grey only as a heavier border, the second exists on no page at all, and the third has no hook anywhere: a sweep of the 55 pages returns no aria-invalid, no required and no error class. Two smaller ones join them: a focus ring, because the grey draws exactly one and only on the field, and the chip tones, because four look-alikes render fourteen states through markup that carries a class for none of them.

Retired. Thirteen rules for one quiet link became one atom, and the five sizes became two. Five chip rules became one base and five tones. Seven slot names got the base they never had, and twenty-one host rules became seven bases plus modifiers. The landing's lp-btn twin is gone, and with it the one rule it had already lost: the 44px floor.

literal Ten places still carry a literal value, each marked LIT in kit.css. Fourteen variables are proposed in inventory.md and none was added: a value enters this system by a named decision, never as a side effect of an extract. Four of the fourteen are pure naming of a literal the file already writes; one is a real 8px difference between the kit's rail and the grey's, and it needs a decision rather than a merge.
