# AGENTS.md

The rules of this repository live in **`CLAUDE.md`** in the root. Read it first: without it
any finding here is a median, not a decision of this project. What this repository is: a
design engineering project for Tendd, a calm subscription tracker (research, IA, a grey
clickable wireframe prototype, the product voice, the visual language). No code runs here;
the material is markdown and markup, and it is checked as text.

1. **Read-only.** Findings come back as a list with `file:line` proof; the owner applies the
   fix after an explicit "we take it". Do not edit files unless asked in plain words.
2. **A finding without proof is not a finding.** Every claim quotes a line that is really in
   the file; if it does not hold on re-reading, it is not submitted.
3. **General advice is noise** ("structure it better", "add examples"). Only falsifiable
   discrepancies: a quote against another quote, a promise with no executor, an artifact
   with no reader, a link that does not resolve.
4. **Deliberate decisions are not defects:** grey wireframes never colored in place, color
   only on copies in `design/`, `index.html` as the product home and `overview.html` as the
   hub, internal md in English. In doubt read `CLAUDE.md` and `docs/decisions.md`.
5. **Your radius is the source, not the render.** Contradictions, orphans, missing states,
   drifted values, broken links, violated rules. "Breaks at 360px" and pixel checks belong
   to the browser pass, not to you.
6. **Answer in Ukrainian.**
