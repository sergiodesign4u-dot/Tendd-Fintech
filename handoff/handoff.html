What a handoff is here, and what it is not

This stage writes no product. Everything a receiver gets was built by the twelve stages above it, and the only question left is whether it travels: whether a person who has never opened this repository can serve it, run its checks, lift the design system into another project and find out what is unfinished without asking anybody.

So this page reports four things and nothing else: the census of what is on disk, the lift test that took the design system's central claim and measured it, the run surface a receiver meets on the first minute, and the open list, counted off design/kit/docs/backlog.md rather than recalled. Every figure here comes from design/kit/screens/handoff13.cjs, which is re-runnable and derives its corpus from the tree rather than from a list somebody typed.

The one thing this page refuses to be is a summary. Twelve stage accounts already exist and each one is better at its own subject than a paragraph here would be. What a receiver needs from this page is the things that are true of the WHOLE and are written down nowhere else.

The lift test

The design system's central claim is that design/system/ is liftable whole. It had been asserted in three places and measured in none, so on 2026-08-18 it was measured: the folder was copied into an empty directory and one screen the system had never seen was assembled there out of its classes alone - the shell, the app bar, the brand lockup, the big total, the interactive trend chart, the segmented range, a prose card, a divided list, the trust block and the five-destination tab bar.

0sideways scroll, 390 and 1440

Every url() inside the folder resolves inside it, including assets/ - which is why those four webp washes are part of the lift rather than decoration. The chart's cursor was built by behaviour.js, the only javascript the system owns, and it works in the empty folder exactly as it works in the product.

And one dependency it cannot provide

base.css asks for Inter by name and nothing in the folder provides it: no @font-face, no file, no import. The lift test passed without noticing, because the machine it ran on has Inter installed, which is exactly the shape of failure a handoff exists to prevent. It is written down now in the two places a person looks - design/system/CLAUDE.md under "What this folder does NOT carry", and at the declaration in base.css, which is the line somebody greps for.

Five weights are actually used: 400, 500, 600, 700 and 800. A subset that drops 800 loses the wordmark. The fallback chain in base.css is deliberate and safe, so a page with no Inter is readable and not broken - it is simply not Tendd.

The run surface

The census asked what a receiver needs before they can open anything, and in its first run the answer was almost nothing existed: no package.json, one file in the whole repository telling a person how to run something, and every instrument resolving playwright from a global npm root - one of them, fp.cjs, from an absolute path inside one machine's npx cache, which was the least liftable line here.

python3 -m http.server 8080 # nothing is built; every page is static html npm install # playwright, the only dependency there is npm run check # the rollout ledger and the quality sweep npm run census # this page's numbers, recomputed

Every instrument now resolves playwright local first and global after, so it runs for a receiver who typed npm install and still runs on a machine that never had one. node_modules/ is ignored; nothing in this repository is built from it and nothing is published.

What is open, counted rather than remembered

Read off design/kit/docs/backlog.md by a script that classifies each row by what it says about itself, so the number cannot drift from the file.

The one row addressed to this stage is the largest structural debt in the repository: a per-component coloured footprint is written by hand in forty places and nothing recomputes it, which is why twenty-one component pages went stale the day the corpus grew. It has an instrument now, counts.cjs, and what it does not have is the discipline of being run - which is the honest state of it and is why it is still open.

Of the 36, 20 are the founder's and are decisions rather than defects: what a fifth of them ask is whether a rule should bend, and a builder may not answer that. The rest are named where they were found, each with the measurement that found it.
